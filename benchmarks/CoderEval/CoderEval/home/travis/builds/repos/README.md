
##CoderEval

The content and the structure of this folder is directly imported from the CoderEval dataset.

Please check the GitHub repository: https://github.com/CoderEval/CoderEval?tab=readme-ov-file

The CoderEval dataset can also be downloaded from: https://drive.google.com/drive/folders/1F8M7e25MgHZ3XJ4RSOGWindFSWC5QOvI?usp=sharing

------

**Important:** As a part of our replication package, we provide different versions of the repositories (under `home/travis/builds/repos`). The newer version of the repository includes minor fixes to ensure a valid Python syntax as well as the few-shot examples in the main functions.

Therefore, if the orignial CoderEval was used, please replace the content in `repos/` with the zip files we provide under *Github Releases* of this repository.
